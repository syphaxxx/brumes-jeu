# Brumes

**Brumes** est un RPG tactique en vue isométrique : des combats sur un terrain en hauteur, une équipe de héros et de créatures, et une vallée noyée dans la brume.

Ce dépôt ne contient que **les versions à télécharger** : rendez-vous sur la page **[Releases](../../releases)**.

## Installer (Windows)

1. Téléchargez le fichier `.zip` de la dernière version.
2. Décompressez-le dans un dossier.
3. Lancez `Brumes.exe`. Gardez le dossier `data` à côté du jeu.

Vos parties de Brumeval sont copiées au premier lancement (Brumeval garde les siennes).

# Brumes (English)

**Brumes** is an isometric tactical RPG: battles on terrain with height, a team of heroes and creatures, and a valley drowned in mist.

This repository only holds **downloadable builds**: see the **[Releases](../../releases)** page.

## Install (Windows)

1. Download the `.zip` of the latest version.
2. Unzip it into a folder.
3. Run `Brumes.exe`. Keep the `data` folder next to the game.
